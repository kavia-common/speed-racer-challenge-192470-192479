This folder contains placeholder assets for the Speed Racer frontend.

- logo.svg: Ocean-blue app logo used in NavBar.
- car_player.svg: Player vehicle top-down placeholder.
- car_ai.svg: AI vehicle top-down placeholder.
- track_pattern.svg: Subtle background pattern used in GameCanvas.
- icon_*.svg: Minimal UI icons for steering, flag, speed.

All assets are lightweight SVG for fast loading and can be replaced with production artwork later.
